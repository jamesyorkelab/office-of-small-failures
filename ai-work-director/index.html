How to direct AI work instead of just writing prompts

AI Work Director separates the job into a goal, delegation level, non-delegable boundaries, quality criteria and human review checkpoints. It is designed for people using AI inside real work where the output still needs judgement.

The skill isn't prompting. It's direction.

A clever instruction cannot compensate for a badly defined job. Direction means deciding what the machine is allowed to do, where it should stop, what evidence it needs and which decisions still belong to a person.

Human review is part of the workflow

Review should happen where errors become expensive: before publication, before irreversible actions, when evidence is weak, or when strategic judgement matters.

Where this fits

If you are still deciding whether the work should be automated at all, start with Should I Automate This?. If the work is part of a wider prioritisation decision, use The Priority Desk. See the Workshop Map for the wider system.

AI Work Director FAQs

Is this a prompt generator?

No. It creates a task brief and division of labour. You can use that brief with any suitable AI system.

Does the tool call an AI model?

No. It runs entirely in the browser.

Why define what must not be delegated?

Because safe and useful AI work is partly about boundaries: decisions, evidence, confidential information, irreversible actions and final accountability.
