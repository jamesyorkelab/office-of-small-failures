# Signal Sample — Case File 004

Integrated into the existing Office of Small Failures static site at:

`/signal-sample/`

## v0 functionality

- brand, competitors and market setup
- fixed 10–20 question panel
- multiple measurement rounds
- manual observations for ChatGPT, Gemini, Perplexity, Google AI Mode, Copilot or Other
- observation date
- brand presence
- citation
- competitor appearances
- accuracy assessment
- evidence / notes
- local browser storage only
- sample size, presence rate, citation rate, competitor presence, accuracy problems
- comparison with previous round
- sample-size warnings
- stakeholder-ready plain-English summary
- CSV export
- JSON backup/import
- lightweight repeat-use / paid-automation intent feedback using local storage plus native share/clipboard

## Deliberate exclusions

No account, database, backend, LLM API, automatic querying, prompt-volume claims, rankings or proprietary composite AI visibility score.

## SEO intent

Natural on-page targeting around:
- how to measure AI search visibility
- AI visibility tracking
- LLM visibility tracking
- ChatGPT brand mentions
- GEO measurement
- AI search measurement framework

## Deployment

This package is a drop-in replacement for the current static Office of Small Failures repository. Preserve the folder structure and commit the changes to the existing GitHub repo; the connected Cloudflare Pages project can deploy from that commit.

## Note about source files

No separate Signal Sample v0 artifact was present in the accessible conversation/library files when this build was made, so the implementation uses the supplied product specification as the functional basis while preserving the existing Office of Small Failures site.
