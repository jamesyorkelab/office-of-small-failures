How this SEO backlog prioritisation tool works

Backlog Court is a free SEO backlog prioritisation tool for teams with several plausible tasks competing for the same delivery slot. Score each task using the same criteria and compare the relative priority instead of letting the newest or loudest request win.

A transparent SEO prioritisation framework

The comparison uses commercial impact, evidence or confidence, urgency, strategic fit and delivery ease. Delivery ease is informed by implementation effort and dependencies.

Prioritise several SEO tasks at once

Use Backlog Court when multiple tasks are individually plausible. Add three to ten tasks, use the same 1–5 scales and compare the resulting order.

Use the score as a decision aid, not a command

The ranking only reflects the assumptions entered. Challenge the weakest assumption in the top case and consider hard deadlines or business constraints outside the model.

Frequently asked questions about SEO backlog prioritisation tools

What is an SEO backlog prioritisation tool?

It compares several SEO tasks using consistent criteria such as impact, evidence, urgency, strategic fit, effort and dependencies.

How is Backlog Court different from an SEO ROI calculator?

An ROI calculator estimates one task; Backlog Court compares several tasks against one another.

What SEO prioritisation framework does it use?

Commercial impact, evidence, urgency, strategic fit and delivery ease.

Should I always do the highest-scoring task first?

No. The score is a structured input, not a command.

How many tasks can I compare?

Three to ten in the current version.
