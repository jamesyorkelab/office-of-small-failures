How the decision is made

03

Commercial impact: 30% — how meaningful the upside is if the task works.

Evidence / confidence: 20% — how much credible evidence supports the expected outcome.

Urgency: 20% — whether waiting materially reduces value or increases risk.

Strategic fit: 15% — how closely the task supports a current business objective.

Delivery ease: 15% — derived from effort and dependency scores. Lower effort and fewer dependencies score better.

The output is a relative comparison between the tasks you entered. It is not a forecast of revenue or a guarantee that the top-ranked task will succeed.

How to prioritise an SEO backlog

SEO prioritisation gets difficult when every task has a reasonable argument behind it. Backlog Court compares competing work using the same visible criteria rather than letting the loudest request or newest idea become the default priority.

Use it for technical SEO fixes, content improvements, landing pages, internal linking, CRO ideas or broader digital work. The purpose is to make trade-offs explicit: commercial impact and urgency matter, but so do evidence, implementation effort and delivery dependencies.

Backlog Court vs WorthDoing

WorthDoing helps assess one SEO task as a commercial case. Backlog Court is for the next question: when several tasks look worthwhile, which one deserves the next delivery slot?
